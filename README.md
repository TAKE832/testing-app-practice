## 概要

COACHTECH 教材 Tutorial 10-5「テスト ハンズオン演習」で作成した成果物です。
（ユーザー登録が正常に動作するかと、emailが重複するとエラーが発生することを検証するテストコードを作成しました。）

## 使用技術

- PHP 8.x
- Laravel 10.x
- PHPUnit（テスト）
- Eloquest / Factory

## 学んだこと

- Featureテストは、CRUD操作などが正常に動作するか確認する際に使用し、Unitテストは、個々の関数やメソッドを確認する際に使用することが分かった。
- RefreshDatabaseトレイトを使用することで、各テストで生成したデータをテストごとにデータベースからリセットすることが分かった。その結果、各テスト間の干渉を防ぎ、個々の動作が正常であるかを確認できるため、テストを行う際は必須であることが分かった。
- practiceで書いたコードはユーザー作成テストと、メールアドレス重複テストでクラスを分けてしまった。また、最低限の情報を書いているsampleとは違い、検証に必要ないデータまで作成してしまった。そのためデータの検証にかかる時間やコードの可読性が低くなってしまっていると感じた。テストを行う際は、必要な情報だけを書くことを意識することで可読性をよくし、他の検証やコード作成に時間を割くようにしたい。

## 詰まったポイントと解決方法

- アサーションメソッドを使って、ユーザーの存在を確認するコードで、$thisと書くところを間違って、$resposeと書いてしまっていた。AIを使って、エラー文を翻訳し、原因を特定することで、動作確認を正常に行うことができた。

## 動作確認

テストコードを書き終えた後、ターミナルで「sail artisan test」を実行することで、各テストがパスされていることを確認した。
